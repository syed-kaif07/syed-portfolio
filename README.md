# Project Technology Stack

Here is an overview of the technology stack used in this portfolio project, categorized by layer.

## ⚙️ Core Framework
| Layer | Technology |
|---|---|
| **Framework** | React 18 + TypeScript |
| **Build Tool** | Vite (with SWC plugin) |
| **Routing** | React Router DOM v6 |

## 🎨 Styling & UI
| Layer | Technology |
|---|---|
| **CSS** | Tailwind CSS v3 |
| **Component Library** | Radix UI (full suite including accordion, dialog, dropdown, etc.) |
| **Animations** | Framer Motion |
| **Icons** | Lucide React |
| **Theming** | next-themes (for dark/light mode support) |

## 🌐 3D / Visual Effects
| Layer | Technology |
|---|---|
| **3D Rendering** | Three.js + `@react-three/fiber` + `@react-three/drei` |
| **Shader Gradients** | `@shadergradient/react` |
| **Smooth Scroll** | Lenis |

## 🧰 Utilities & Forms
| Layer | Technology |
|---|---|
| **Forms** | React Hook Form + Zod (for validation) |
| **Data Fetching** | TanStack Query (React Query v5) |
| **Date Utils** | date-fns |
| **Class Utils** | clsx + tailwind-merge + Class Variance Authority (CVA) |
| **Other Utils** | input-otp, embla-carousel-react, react-resizable-panels |

## 🧪 Testing & Development
| Layer | Technology |
|---|---|
| **Unit Tests** | Vitest + Testing Library (`@testing-library/react`, `@testing-library/jest-dom`) |
| **E2E Tests** | Playwright |
| **Linting & Formatting**| ESLint + TypeScript ESLint |
| **Other Tools** | PostCSS, Autoprefixer |

## 📊 Analytics & Deployment Environment
| Layer | Technology |
|---|---|
| **Analytics** | Vercel Analytics |
| **Node Engine** | Node 24.x |
